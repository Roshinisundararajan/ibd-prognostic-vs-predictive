# Data

## What is committed here

- `genesets/hallmark.gmt` — the 50 MSigDB Hallmark gene sets, built by
  `../00a_fetch_hallmark_genesets.R`.
- `signatures/` — the thirteen published signature gene lists used in objective (ii),
  taken from the supplementary tables of the original papers. The eleven Linggi
  metabolism and stress-response modules are rebuilt by
  `../00b_fetch_reactome_signatures.R`; the Martin GIMATS and Czarnewski UC1 lists were
  curated by hand.
- `GSE206285/GSE206285_additional_sample_metadata.tsv.gz` — the small per-sample
  metadata file that accompanies the series.

For Martin et al. (2019) the GIMATS module was taken at adjusted p < 0.01 and absolute
log2 fold change at least 1, a threshold the paper does not state, giving 52 up and 19
down genes. For Czarnewski et al. (2019) the UC1 list gave 231 up and 53 down genes.
Older array aliases are carried alongside current symbols (CXCL8/IL8, MZB1/MGC29506,
JAML/AMICA1 among others) so that one gene set applies across platforms.

## What is not committed, and how to get it

The expression data are not in this repository. They are large, they belong to the
original depositors, and they are fully regenerated by the scripts:

| File | Size | Produced by |
|---|---|---|
| `GSE206285_series_matrix.txt.gz` | 77 MB | `01_download_annotate.R` |
| `GSE206285_eset.rds` | 99 MB | `01_download_annotate.R` |
| `GPL13158.soft.gz` | 56 MB | `01_download_annotate.R` |
| `../out/01_expr_GSE206285.rds` | 34 MB | `01_download_annotate.R` |
| `../out/02_cohort_GSE206285.rds` | 57 MB | `02_build_cohort.R` |

From `analysis/`:

```bash
mkdir -p out
Rscript 01_download_annotate.R
Rscript 02_build_cohort.R
```

The download is several gigabytes over the wire and takes a while on a slow connection.
The series are public:
[GSE206285](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE206285),
[GSE73661](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE73661),
[GSE207022](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE207022).
